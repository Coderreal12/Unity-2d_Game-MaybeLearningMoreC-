2D Platformer!

This game is a platformer where you need to collect 5 coins to win! Each coin is spread all across the map and once you get all 5 your time is shown in the bottom left and you get the win screen!

Controlls:
W -- Jump
A -- Left
D -- Right

I made this game to get more comfortable with coding in C # (Learning logic and syntax) and to learn more about Unity!
Some things that I learned from this are

- Parenting objects via scripts
- Animation With 2d sprites
- Raycasting
- Collision with 2d Objects
- Better coding habits.

I will explain what I mean down below.

Under The Hood:
This was very fun to make as this is my first time using animations and 2d sprites!

 
  
  Parenting Objects:
What was hard to make was the moving platforms. At first, I tried using Rigidbody and time. delta time and all of the stuff like that; however, in the end I just ended up doing my research and 
finding out that I should parent the object on collision from a raycast!

Raycasting:
This was also my first time using raycasting, and at first I was scared of using them; however, I realized it's just a position and a direction!

Coding:
That to say I had one big hiccup and that was my code. This game really taught me what it means to have orginzed and structured code. In the middle of making It I realzied I had no Idea what anything meant. 
So I had to rewrite everything but this time I made it better. I used so much more funcitons and comments instead of just splattering code onto the canvas and hoping it sticks.

Collision:
I also leanred how collision with 2d Objects works and how its differnt from 3d to where you only use a vector2d insead of 3d.
